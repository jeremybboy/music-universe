# Contributing

Keep changes focused on the local browser player. Install with `npm ci`, start with `npm run dev`, and run `npm test` and `npm run build` before opening a pull request. For changes to audio timing or playback, run the browser test described in the README and describe what you heard as well as what the checks measured.

Open a branch against `main` and explain the user-visible change and its verification in the pull request. Keep source audio archives, third-party samples and credentials out of the repository.
