# Music Universe

The browser UI is in `frontend/`, the composition and intent rules are in `music/`, and the audio driven renderer is in `visualization/`. The Mac wrapper and icon source are in `macos/`. See the README for launch and checks.

- Inspect status, default branch, instructions and existing PRs before editing.
- Work on a focused branch after bootstrap. Stage explicit paths and review the complete diff. The owner merges PRs.
- Keep credentials, source audio archives, reference WAVs and private paths out of Git.
- Keep note scheduling under one audio clock. Do not put network or model calls on the audio path.
